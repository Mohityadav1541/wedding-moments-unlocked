# Wedding Moments AI - 100% FREE Gradio Space

This is a free AI face recognition service powered by **Gradio** and **InsightFace**.

## 🚀 How to deploy on Hugging Face (100% FREE):

1. **Select SDK**: Select **Gradio** (Selected by default - 100% FREE!).
2. **Upload Files**:
   Upload `app.py` and `requirements.txt` from this folder.
3. **Copy Space URL**:
   Your public API URL will be:
   `https://<your-username>-<space-name>.hf.space`

This Space is configured for CPU hardware because the application uses
InsightFace with `CPUExecutionProvider`. Do not select ZeroGPU unless the
application is changed to use a `@spaces.GPU` function and GPU-compatible
runtime dependencies.
